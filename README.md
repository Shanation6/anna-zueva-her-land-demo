# Её земля · Анна Зуева

Статическая демонстрационная концепция. Slug репозитория: `anna-zueva-her-land-demo`. Не официальный сайт, не публичная оферта, не открытый набор.

## Проверенный источник

Публичная страница Telegram, полученная 8 ноября 2026 через Python urllib: https://t.me/AnnaArmveli. Локальное фото assets/anna.jpg скачано по og:image этого публичного профиля; его использование на официальном сайте необходимо согласовать с владельцем. Декоративный рельеф — авторский SVG, не фото места встреч.

Точное описание профиля на момент проверки: «Психолог Processwork, творческие психологические сессии, очно и онлайн». Имя профиля: «Анна».

Данные в пользовательском брифе (полное имя, специализация групп, город и название проекта) использованы как ориентир демо. Публичный профиль не подтверждает все эти подробности. Детальные тексты, название программы, актуальность набора, образование, стоимость, расписание, адрес и условия участия необходимо согласовать с владельцем перед запуском. Отзывы, результаты, цены и даты не придуманы.

## Запуск

Открыть `index.html` напрямую либо `python -m http.server 4203`. Сборки, сервера приложения, внешних библиотек, форм, авторизации, трекеров и cookies нет. Все шрифты и изображения локальные. Лицензии шрифтов находятся в assets. Навигация и FAQ работают без JavaScript; переключатель подготавливает вопрос для личного разговора, не оценивает состояние и не подбирает лечение. Главный призыв открывает точный Telegram из брифа.

## Проверка

8 ноября 2026: Chromium, ширины 360, 390, 768 и 1440 px — без горизонтального переполнения и ошибок JavaScript; все якоря, локальные изображения и шрифты загружены; переключатель обновляет заголовок и текст, FAQ раскрывается, первый Tab фокусирует ссылку пропуска. Проверка выполнена с reduced motion. При отключённом JavaScript видны основной текст и подсказка, FAQ работает. Скриншоты и qa.json находятся в игнорируемой папке outputs; общий сценарий проверки — в соседнем демо Альфии, .work/qa.mjs.

## Дизайн

Страница проекта как личный ландшафт: широкая типографическая композиция, рельефные SVG-линии, оливковая палитра, локальный реальный портрет из публичного профиля. Интерактивный «ориентир» помогает назвать вопрос, не диагностирует и не обещает результат. На мобильном рельеф и портрет становятся отдельными спокойными блоками, три этапа знакомства превращаются в вертикальный ряд. Визуально просмотрены desktop и mobile, а также состояние переключателя. Все элементы работают без сторонних библиотек.
